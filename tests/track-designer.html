    How to edit

    • Drag a white corner to move it. Drag the map to pan, scroll or use + and − to zoom.
    • Click a small + between corners to add one.
    • Select a corner to set how tight it is. Small radius makes a hairpin.
    • Lake mode reshapes the lake the same way.
    • The race goes the same way as the arrows. Grid and start line stay on the main straight.
